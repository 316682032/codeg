<details>
<summary><strong>ウィンドウごとのタブ</strong> の詳細</summary>
<br/>

- 設定 → 一般の「ウィンドウ間で会話タブを同期」で切り替えます。既定はオンで、同じサーバーにつながるすべてのウィンドウとデバイス（PC、タブレット、スマートフォン）が公式版と同じく一つのタブセットを共有します。
- オフにすると、あるウィンドウで会話タブを開く・切り替える・閉じても他のウィンドウはそのままで、再読み込みするとそのウィンドウ自身のタブが戻ります。
- 会話、メッセージ、削除はこの設定に関係なく、常にすべてのウィンドウに反映されます。
- この設定はサーバーに保存されます。どのウィンドウやデバイスで切り替えても、そのサーバーにつながるすべてのウィンドウとデバイスが一緒に切り替わります（0.35.2-1 以前はブラウザごとに保存され、ブラウザでは既定でオフでした）。
- 上流への要望：[spacering-net/codeg#547](https://github.com/spacering-net/codeg/issues/547)。

</details>

<details>
<summary><strong>Claude Code の思考を表示</strong> の詳細</summary>
<br/>

- 新しいモデルでは、公式版には思考の暗号化された署名しか返らないため、Claude の思考欄は空のままです。
- このビルドは API に思考の要約を要求します。ターミナルの `claude` で `showThinkingSummaries` をオンにしたときと同じ内容です。
- 不要なら、`~/.claude/settings.json`（またはプロジェクトの `.claude/settings.json`）に次を追加してください：

  ```json
  "showThinkingSummaries": false
  ```

- 以前の会話では思考テキスト自体が返されていないため、後から復元することはできません。

</details>

<details>
<summary><strong>返信とメッセージの翻訳</strong> の詳細</summary>
<br/>

- 「設定 → 翻訳」で [Alibaba Cloud Bailian](https://bailian.console.aliyun.com/) または [Tencent Cloud TokenHub](https://console.cloud.tencent.com/tokenhub/apikey) の API キーを入れると使えます。料金は各プラットフォームの規定どおりです。既定は Bailian の `qwen-mt-flash` で、テストでは 1 段落約 0.5 秒でした。
- 返信：「返信の翻訳」のスイッチをオンにすると、エージェントが返信をひとまとまり書き終えるたびに（ツール呼び出しや思考に移ったとき、またはターンが終わったとき）、そのまとまり全体を 1 回のリクエストで翻訳し（モデルはまとまり全体を文脈として見られます）、原文の代わりに訳文を表示します。書いている間は原文を表示します。各返信の下の翻訳ボタンで原文に戻せます。自動翻訳がオフのときは、そのボタンでその返信だけを翻訳できます。思考は展開したときに翻訳し、同じボタンで切り替わります。コードブロックとツール呼び出しは翻訳しません。コピーボタンは表示中の内容をコピーします。
- セッション名：返信の自動翻訳がオンのとき、エージェントが付けたセッション名もサイドバー、タブ、会話のタイトルバーであなたの言語で表示します。自分で付けた名前は翻訳せず、サイドバーのセッションにカーソルを合わせると元の名前が見られます。
- 質問カード：エージェントが質問すると、質問と選択肢を既定で訳文表示します（「設定 → 翻訳」でオフにできます）。カード右上のボタンで原文と訳文を切り替えられ、回答はエージェントが示した元の選択肢のまま送られます。「その他」に書いた回答は、横の翻訳ボタンか `⌘⇧L` で目的の言語に翻訳でき、もう一度押すと元に戻ります。「送信時に翻訳」がオンなら送信前に自動で翻訳します。秘密扱いの質問は翻訳に送りません。
- ToDo リスト：エージェントが立てた ToDo リスト（返信内のプランカード、会話上部のフローティングプラン、セッション詳細のプラン）は、各ステップを既定で訳文表示し、リスト全体を 1 回のリクエストで翻訳します（「設定 → 翻訳」の「ToDo リストを自動で翻訳」でオフにできます）。プランカード右上のボタンで原文と訳文を切り替えられ、自動翻訳がオフのときはこのボタンで手動翻訳します。
- メッセージ：入力欄の翻訳ボタン、`⌘⇧L`（Windows と Linux では `Ctrl+Shift+L`）、または右クリックメニューで、入力欄の内容をその場で目的の言語（既定は英語）に翻訳します。メンション、スラッシュコマンド、パス、コードはそのまま残り、`⌘Z` で一度に原文へ戻せます。翻訳するのは押したときだけで、書きかけの下書きが送られることはありません。「送信時に翻訳」をオンにすることもできます。送信後は、メッセージ横の翻訳ボタンで翻訳前に書いた原文に切り替えられ、コピーも表示中の内容に従います。
- レート制限にかかると `qwen-mt-lite` またはもう一方のエンジンに切り替えます。用語集で固有名詞の訳し方を固定できます。訳語を空欄にすると、その用語は原文のまま残ります。
- API キーは OS のキーチェーン（サーバー版ではデータディレクトリの `tokens.json`）に保存し、データベースには書きません。翻訳リクエストはプロキシを通さず直接接続し、プロキシ経由でしか外に出られないネットワークでは自動でプロキシを使います。
- 返信の訳文は表示用で、会話履歴にはエージェントの原文が残ります。メッセージの翻訳前の原文はローカルのデータベースに別途保存され、翻訳キャッシュを消去しても消えません。

</details>

<details>
<summary><strong>Claude Code サブエージェントのセッション</strong> の詳細</summary>
<br/>

- Claude Code は各サブエージェント（Agent / Task ツール）の会話全体を `~/.claude/projects/<プロジェクト>/<セッション id>/subagents/agent-<id>.jsonl` に別ファイルで保存します。公式版のカードには処理の要約と最終結果しかなく（バックグラウンドのものは要約もなし）、このファイルは開けません。
- このビルドではカードのタイトルの横に「サブエージェントのセッションを表示」ボタンを追加し、右側のパネルでこの記録を開きます。受け取ったタスク、思考、返信、各ツール呼び出しの入力と出力が見られます。Codex や Grok のサブエージェントのカードにあるのと同じボタンです。
- ボタンはサブエージェントが起動するとすぐに出ます（フォアグラウンドでもバックグラウンドでも同じ）。実行中に開くと 2 秒ごとに更新され、実行中のツール呼び出しは実行中と表示されます。会話を再読み込みした後に開くとその時点の内容なので、閉じて開き直すと最新になります。
- 以前の会話でも、記録ファイルが残っていれば見られます。

</details>

<details>
<summary><strong>スマホで開いている会話をすばやく切り替え</strong> の詳細</summary>
<br/>

- 画面の幅が 768 ピクセル未満のとき（スマホや、ごく狭いブラウザーのウィンドウ）、公式版は会話タブのバーを表示しません。開いている別の会話に移るには、サイドバーの履歴全体から探すしかありません。完了した会話はサイドバーで既定で非表示なので、開いていても見つかりません。
- このビルドでは会話のタイトルがボタンになります。タイトルの後ろに ⌄ と開いている会話の数が付き、ほかの会話が許可や回答を待っている間は数字にオレンジの点が付きます。タップすると下から「開いている会話」が開き、開いている会話をすべてタブの順に、それぞれの状態（対応待ち、進行中、レビュー、完了、キャンセル済み、未送信）付きで一覧します。タップで切り替え、× で閉じます。新しい会話を始めたり、「すべての会話（履歴を含む）」でサイドバーを開いたりもできます。外側をタップする、下へドラッグする、または戻るジェスチャーで閉じます。
- 「対応待ち」は、この端末がその会話に接続しているときにしか分かりません。この端末で一度でも開いた会話に表示され、開いていない会話には保存された状態が表示されます。
- 「ウィンドウ間で会話タブを同期」がオン（既定）のときは、スマホで閉じた会話は PC でも閉じます。PC でタブを閉じたときと同じです。
- 幅 768 ピクセル以上（PC、タブレット）では何も変わらず、タブのバーのままです。
- 対応する要望：[keh4l/codeg#10](https://github.com/keh4l/codeg/issues/10)。

</details>

<details>
<summary><strong>エージェントが画像を生成</strong> の詳細</summary>
<br/>

- 「設定 → 画像生成」でサービスを追加します。API の種類は「OpenAI API」（OpenAI 公式、Grok、大半の中継サーバー）か「Gemini API」（Google 公式または中継サーバー）を選び、アドレスは空欄なら公式のものになります。キーと、`gpt-image-2`、`grok-imagine-image-2.0`、`gemini-3-pro-image` などのモデル名を入力します。複数追加できます。「テスト」は低画質の小さな画像を 1 枚生成して動作を確認します（サービス側で課金されます）。
- ページ上部のスイッチ（「設定 → コラボレーション → 会話内ツール」の「画像を生成」と同じもの、既定はオフ）をオンにし、少なくとも 1 つのサービスにキーとモデルがあれば、それ以降に起動したエージェントに `image_generate` と `image_get_result` の 2 つのツールが加わります。エージェントはモデル、縦横比、解像度、透明な背景を選べ、参考画像を渡して既存の画像を編集することもできます。モデルを指定しなければ設定の既定のモデルを使います。
- 保存先はエージェントが指定します。相対パスは会話の作業フォルダーから解決されます。指定がなければ `~/.codeg/generated-images/<日付>/` に保存され、このフォルダーは設定で変えられます。
- 会話には画像ごとにカードが表示されます。生成中は経過秒数、完了後は画像、保存先（クリックで開く）、サービスとモデル、サイズ、所要時間です。画像はファイルから読むので、会話を読み込み直してもファイルがある限り表示されます。
- 既定では幅約 512 ピクセルの縮小版もエージェントに渡し、結果を見てから手直しするか決められるようにします。エージェントのコンテキストを少し使います。エージェントのモデルが画像を読めない場合は設定でオフにしてください。
- 画像 1 枚には数十秒から 2 分ほどかかることがよくあります。エージェントが 1 回のツール呼び出しで待てる時間を超えるときは、先にジョブ ID を返し、エージェントは `image_get_result` で受け取ります（次の項を参照）。
- API を呼ぶのは Codeg 自身で、エージェントが受け取るのは画像ファイルだけです。API キーはシステムのキーチェーン（サーバー版はデータフォルダーの `tokens.json`）に保存され、データベースには書かれず、設定の同期にも含まれません。

</details>

<details>
<summary><strong>タイムアウトが短いエージェントでも結果を待てる</strong> の詳細</summary>
<br/>

- MCP ツール呼び出し 1 回をどれだけ待つかはエージェントによって違います。ZCode は 30 秒、Cursor・Kimi・DeepSeek・OpenCode は 60 秒、Codex は 5 分、Claude Code・Qoder・CodeBuddy・Grok は実質無制限です。公式版では `get_delegation_status`（委任したタスクの結果待ち）は 1 回で長く待つことがあり、`ask_user_question`（あなたへの質問）は回答があるまで待ち続けます。期限を過ぎるとエージェントは呼び出しが失敗したとみなして先へ進むので、質問は未回答扱いになります。
- このビルドはこれらのツールに、エージェントごとに期限より短い上限を設けます。たとえば ZCode は 20 秒、OpenCode は 45 秒、Codex は 4 分です。期限のないエージェントには上限を設けず、公式版と同じです。上限までに結果が出なければいったん返し、続けて待つ方法をエージェントに伝えます。
- 質問：その時点で未回答なら質問カードはそのまま残り、エージェントは新しいツール `get_question_answer` で待ち続けます。回答すると、答えは元の質問カードに表示されます。
- 委任したタスク：`get_delegation_status` は 1 回につき上限まで待ち、その時点のタスクの状態を返します。画像生成も同じです（前の項を参照）。
- 待っている間は 10 秒ごとにエージェントへ進捗を知らせるので、OpenCode のように進捗で期限を延ばすエージェントはより長く待てます。

</details>

<details>
<summary><strong>使うエージェントだけを一覧に</strong> の詳細</summary>
<br/>

- 組み込みエージェントは 20 近くあり、公式版はインストールの有無に関係なくすべて有効にします。設定画面は長い一覧になり、新しい会話のピッカーも未インストールのエージェントで埋まり（会話画面はインストールしないので、選んでも使えません）、設定画面を開くたびに全エージェントを事前チェックします。
- このビルドの設定 → エージェントには「マイエージェント」だけが並び、ドラッグで並べ替えもできます。タイトルバーの「追加」と一覧の下の行から「エージェントを追加」を開けます。名前や説明で検索し、インストール済み / 未インストールで絞り込め、このマシンにインストール済みのものが先頭に並び、まとめて追加できます。未インストールのものは、追加したあと詳細からインストールします。
- 詳細のスイッチが「マイエージェント」です。オフにすると一覧から外れ、元に戻せます。公式版の「有効」と同じ設定なので、新しい会話のピッカーや委任など、ほかの場所もこれに従います。
- 設定画面を開いたときに事前チェックするのは「マイエージェント」だけで、ほかのエージェントは開いたときにチェックします。
- codeg にまだそのエージェントの設定がないとき（新規インストール、または後のリリースで加わった組み込みエージェント）は、このマシンでインストール済みと検出されたものだけを有効にします。codeg のいう「インストール済み」は、使う ACP アダプターや CLI がそろっていることなので、新規インストール直後は一つもないことが多く、一覧は空から始まります。「エージェントを追加」から選んでください。あとでインストールしたエージェントが自動で加わることはなく、既存の設定は変わりません。
- 以前のビルドから更新して「マイエージェント」に未インストールのものがある場合、一覧の上に一度だけ「インストール済みだけ残す」か「このままにする」かを尋ねるヒントが出ます（選択はデバイスごとに記憶）。
- 新しい会話のピッカーの列の最後に「+」が加わり、押すと「エージェントを追加」が開きます。エージェントが多くて収まらないときは「その他」メニューの最後にあります。有効なエージェントが一つもないときのボタンも「エージェントを追加」を開きます。

</details>

## インストール

### デスクトップ

[Releases](https://github.com/keh4l/codeg/releases/latest) から最新のインストーラーをダウンロードしてください：

| OS | インストーラー |
| --- | --- |
| macOS（Apple シリコンまたは Intel） | `.dmg` |
| Windows（x64 または ARM64） | `-setup.exe` |
| Linux | `.deb`・`.rpm`・`.AppImage` |

公式の Codeg と同じアプリとしてインストールされ、公式版を置き換えます。会話と設定はそのまま残ります。

> [!NOTE]
> macOS で初回起動時に「壊れている」「開けません」と表示された場合は、次のコマンドを一度だけ実行するか、「システム設定 → プライバシーとセキュリティ」で開くことを許可してください：
>
> ```bash
> xattr -cr /Applications/codeg.app
> ```

### サーバー

Linux または macOS：

```bash
curl -fsSL https://raw.githubusercontent.com/keh4l/codeg/keh4l/install.sh | bash
CODEG_STATIC_DIR=/usr/local/share/codeg/web codeg-server
```

Windows（PowerShell）：

```powershell
irm https://raw.githubusercontent.com/keh4l/codeg/keh4l/install.ps1 | iex
$env:CODEG_STATIC_DIR="$env:LOCALAPPDATA\codeg\web"; codeg-server
```

どちらもこのリポジトリのリリースからインストールされ、サーバーの組み込みアップデートもここを使います。

### 公式版に戻すとき

> [!WARNING]
> まず Codeg のデータをバックアップしてください。このビルドには公式版にないデータベース移行（翻訳機能のテーブルなど）があり、公式版は同じデータで起動できない場合があります。
